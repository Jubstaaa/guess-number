# Guess Number

A number guessing game made in Unity. The game picks a random number between 0 and 9998 and tells you after each guess whether to go higher or lower.

## Gameplay

- Type a number and press Enter or the Guess button. The button is disabled while the input is empty.
- The game answers "Increase" or "Decrease" and shows your last guess.
- Guessing the number opens the result screen, where you can play again or exit.

## Stack

- Unity 2022.3.13f1
- C# scripts in `Assets/Scripts`
- TextMesh Pro for UI text and input

## Running it

Open the folder in Unity 2022.3.13f1, open `Assets/Scenes/Menu.unity` and press Play. The scenes are Menu, Ingame and Result.
